Générateur de projet

Remplis le formulaire, clique sur "Générer", copie le résultat et colle-le dans ton site. Aucun code à écrire.

1 · Infos de la carte

Ce qui s'affiche dans la grille de projets sur la page d'accueil.

2 · Liens

Les deux boutons affichés sous la description.

3 · Page détail (si case cochée ci-dessus)

Ces infos remplissent la page complète du projet, avec sa galerie photo.

Comment faire :
  1. Ouvre index.html avec un éditeur de texte (Bloc-notes, VS Code...)
  2. Cherche (Ctrl+F) la dernière carte projet, juste avant </div></section>
  3. Colle le Bloc 1 juste avant cette ligne, enregistre
  4. Si tu as une page dédiée : colle le Bloc 2 dans un nouveau fichier, enregistre-le au même endroit que index.html sous le nom indiqué
  5. Ajoute tes photos dans le dossier images/ avec les noms exacts indiqués
